# 物联灵瞳 —— 智慧停车场综合管理系统

> 基于 STM32F103C8T6 的智慧停车场物联网综合管理系统，集成 8 大子系统协同工作，实现从车牌识别入场、窄弯会车调度、盲区预警到车位监测、环境安全联动的全场景覆盖。每个子系统使用独立 STM32 开发板，资源充足、互不依赖。

## 核心功能

| 子系统 | 传感器/执行器 | 功能描述 |
|--------|--------------|----------|
| **无人值守通行系统** | 串口 / 舵机 / HC-SR04 | 接收 PC 下发的车牌，超声波检测车辆距离，道闸状态机自动抬杆/落杆（非阻塞 + 防砸 + 超时保护），OLED 显示车牌/剩余车位/距离 |
| **窄弯道智能协同会车** | 双路 HC-SR04 / 双 OLED / 蜂鸣器 | 双传感器检测窄弯两侧车辆，冲突时协调通行，蜂鸣器提示，双 OLED 分屏显示 |
| **立柱盲区检测系统** | HC-SR04 / OLED / 蜂鸣器 | 检测柱子后方盲区障碍物，距离 ≤30cm 触发蜂鸣器声光报警 |
| **智能车位管理** | HC-SR04 / 红绿 LED / 蜂鸣器 | 超声波判断车位占用（≤100cm 判占用），红灯占位/绿灯空闲，超温蜂鸣报警 |
| **环境检测网络** | MQ-2 烟雾传感器 | 实时检测停车场烟雾浓度(ppm)，OLED 显示 + 串口数据上报 |
| **安全预警体系** | 热敏(NTC) / 直流电机 / 蜂鸣器 | 热敏 ADC 测温，超过阈值自动开启排烟风扇并蜂鸣报警，OLED 显示温度与转速 |
| **智能防汛排水监控** | 雨滴传感器 / 水位传感器 / 继电器 / 水泵 | 监测雨量和水位，超警戒自动启动水泵排水，水位降至安全线以下自动关闭 |
| **智能感光调光** | 光敏传感器 / PWM LED | 光敏 ADC 检测环境光照，非线性映射 PWM 调节照明亮度 |

## 功能描述

一、无人值守通行系统
基于 USART + DMA 循环接收 + IDLE 空闲线中断 + 双缓冲（dma_rx_buf 接收 / rx_parse_buf 解析职责分离）接收 PC 端下发的不定长车牌帧。自定义帧格式 `[AA][55][CMD][LEN][DATA][累加和][0D][0A]`，主循环内做帧头、指令码、长度、帧尾 + 累加和四重校验，并通过本地去重（车牌没变不刷新 OLED）避免重复刷屏。结合 HC-SR04 超声波测距判断车辆到达，通过 PWM 控制 SG90 舵机实现道闸自动抬杆/落杆（非阻塞状态机：去掉阻塞延时、落杆中防砸、动作超时回归安全位），OLED 实时显示车牌、剩余车位与距离，IWDG 独立看门狗保障长时间运行稳定。

二、窄弯道智能协同会车系统
针对停车场窄弯双向来车冲突场景，部署双路 HC-SR04 分别检测两侧车辆接近情况。当任一侧车辆进入检测范围（≤1000mm）时蜂鸣器提示，双 OLED 分屏实时显示两侧距离与通行状态；当两侧同时来车时进入冲突协调，明确一方优先通行、另一方等待，并持续蜂鸣提醒直至冲突解除。系统有效解决窄弯会车冲突，提升通行效率与安全性。

三、立柱盲区检测系统
针对转角柱后视觉盲区碰撞隐患，利用 HC-SR04 超声波传感器部署于柱体侧后方，基于 EXTI 外部中断 + TIM 定时器精确测量障碍物距离。当检测到盲区范围内（≤30cm）存在障碍物或行人时，立即触发蜂鸣器报警，OLED 实时展示距离与预警状态，实现转角盲区的主动安全预警。

四、智能车位管理系统
利用 HC-SR04 超声波传感器安装于车位上方，通过测距数据与阈值对比（≤100cm 判占用）判断车位占用状态。空闲时绿灯指示，占用时红灯指示，OLED 实时显示距离、温度与占用状态。同时集成超温蜂鸣报警功能，当环境温度超过阈值时触发安全告警。

五、环境检测网络系统
基于 MQ-2 烟雾传感器实时检测停车场烟雾浓度，模拟信号经 AO 引脚输出，由 ADC 单通道软件触发采样并多次均值滤波，降低单次采样噪声。采样值经换算公式得到 ppm 浓度后，OLED 实时展示浓度数值，同时通过串口打印上报。

六、安全预警体系系统
利用热敏电阻(NTC)实时监测环境温度，经 ADC 单通道连续转换 + 软件触发采样，多次滑动平均滤波后，通过分压关系反推阻值、贝塔公式换算温度，OLED 显示当前温度。当温度超过安全阈值时，自动启动直流电机驱动排烟风扇（PWM 调速），同步触发蜂鸣器报警；温度回落后自动关闭排烟设备。

七、智能防汛排水监控系统
集成雨滴传感器与水位传感器双重监测，两者均通过 AO 模拟引脚输出，ADC 单通道软件触发采样并多次均值滤波。依据广东雨季特点设定阈值：当降雨量超阈值且水位达警戒线时，通过继电器驱动水泵自动启动排水，蜂鸣器报警，OLED 实时显示雨量、水位与水泵运行状态；水位降至安全线以下后自动关闭水泵，实现智能排水闭环控制。

八、智能感光调光系统
基于光敏传感器检测环境光照强度，经 ADC 单通道连续转换 + 软件触发采样，通过非线性亮度映射算法（2.2 次幂曲线）将 ADC 值换算为目标亮度百分比，动态调节 PWM 占空比控制 LED 照明亮度。光照充足时降低亮度节能，不足时自动提升亮度保障照明，实现停车场照明的智能化节能管理。

## 技术栈

| 层级 | 技术 |
|------|------|
| 主控 | STM32F103C8T6 (ARM Cortex-M3, 72MHz) |
| 传感器 | HC-SR04 超声波、MQ-2 烟雾传感器、热敏电阻(NTC)、光敏传感器、雨滴传感器、水位传感器 |
| 执行器 | SG90 舵机、直流电机、继电器 + 水泵、LED、蜂鸣器 |
| 显示 | OLED (I2C, 0.96 英寸) |
| 通信 | USART 串口（DMA + IDLE 空闲线中断接收） |
| 外设 | GPIO、ADC、EXTI、TIM/PWM、IWDG 独立看门狗、DMA |

## 使用说明

1. **硬件连接**：各子系统独立接线，按各自模块的 `Hardware/` 目录下引脚定义连接传感器与执行器
2. **固件编译**：使用 Keil MDK 打开对应子系统目录下的 `.uvprojx` 工程文件，编译烧录
3. **独立运行**：各子系统均可独立运行与演示，互不依赖
4. **系统联调**：全部 8 个子系统同时上电即可构成完整的智慧停车场综合管理系统
